GENOMIC LANGUAGE MODELS · SPARSE ATTENTION

Native Sparse Attention for RNA Secondary Structure Modeling

Co-authored with Amadeo Tunyi, Denis Werner, Samuel Zirbo · Supervised by Tilman Hoffbauer

Does Native Sparse Attention preserve long-range RNA base-pair dependencies better than pooling attention, while retaining practical computational efficiency?

Overview

Genomic language models can learn long-range dependencies between nucleotides that are important for RNA structure. Base pairs may connect positions hundreds or thousands of nucleotides apart. However, standard full self-attention has quadratic time and memory scaling with sequence length, making long sequences computationally expensive. Pooling-based approaches can reduce this cost, but may lose token-level detail needed to predict individual base-pair interactions.

This project evaluated Native Sparse Attention (NSA) against pooling attention and a full-attention baseline on simulated RNA sequences, measuring predictive accuracy, dependency maps, GPU memory, and runtime.

Research questions

  • RQ1: Can NSA capture long-range RNA base-pair interactions better than pooling attention?
  • RQ2: Can the improvement retain the computational efficiency needed for long-sequence genomic modeling?

Method

We implement Native Sparse Attention (NSA) in a BERT-style genomic language model and compare it with the full self-attention and the pooling attention baselines. NSA combines local attention, compressed global context, and selective full-resolution attention over the most relevant blocks. We use PyTorch FlexAttention to implement the selective branch efficiently without materializing the full attention matrix.

We train on simulated variants of a single 1,219-nucleotide telomerase RNA sequence from the RFAM database, using mutation and BERT-style masking. We evaluate masked nucleotide prediction accuracy, paired-position accuracy, peak GPU memory, and training runtime. Paired accuracy measures prediction performance specifically at nucleotides involved in annotated base pairs, providing a targeted measure of the model’s ability to learn structural dependencies.

Results

Model Accuracy

0.77 NSA paired accuracy
0.58 Pooling paired accuracy
0.92 Full attention paired accuracy

The main accuracy comparison uses each method's worst-case hyperparameter configuration; the efficiency comparison uses each method's best-case configuration.

Efficiency comparison

1,758 MB NSA peak GPU allocation
1,426 MB Pooling peak GPU allocation
3,791 MB Full attention peak GPU allocation

In the best-case efficiency configurations, per-step runtime was 32.7 ms for NSA, 27.9 ms for pooling, and 67.7 ms for full attention. NSA used less memory and ran faster than full attention, but cost more than pooling in this implementation.

Interpretation

NSA substantially improves paired-nucleotide prediction over pooling attention (0.77 vs. 0.58 in the evaluated configurations), bringing performance closer to full attention (0.92). This suggests that selectively restoring token-level resolution within relevant blocks helps preserve long-range structural dependencies that coarse pooling can lose. NSA also offers a favorable efficiency trade-off: it uses less GPU memory and runs faster than full attention, although pooling remains more efficient.

The result is a trade-off, not a universal win: NSA improves paired accuracy over pooling in the tested setup, while pooling remains more efficient in the current implementation. Moreover, the experiments use a single RNA sequence with independently simulated mutations, so generalization to other RNA families remains untested.

Limitations

  • Evaluation focused on a single RNA family and sequence, so generalization is unconfirmed.
  • Simulated mutations were independently sampled and may simplify real evolutionary variation.
  • NSA did not yet use sequence packing, likely overstating its efficiency cost relative to packed baselines.
  • Ground-truth contacts came from an RFAM consensus structure and may not match every individual sequence.
